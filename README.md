Автоматическое объединение, очистка и анализ Excel-файлов на Python.

## 🎯 Что делает программа

Программа решает типичную бизнес-задачу: **объединение десятков Excel-отчетов в один файл за 3 секунды**.

**Без программы:** бухгалтер тратит 3–4 часа на ручное сведение данных, поиск дубликатов и исправление форматов.  
**С программой:** 3 секунды, 0 ошибок, готовая аналитика.

### Возможности:
- ✅ Автоматически находит все `.xlsx` файлы в папке
- ✅ Объединяет их в единую таблицу
- ✅ Удаляет дубликаты и пустые строки
- ✅ Универсально определяет колонки по ключевым словам
- ✅ Преобразует даты и числа в корректный формат
- ✅ Создает сводную таблицу с итогами
- ✅ Сохраняет результат в Excel с двумя листами: "Все данные", "Итоги"

## 🚀 Как использовать

## 1. Установка зависимостей
```bash
pip install pandas openpyxl
```
### 2. Запуск
Положите ваши Excel-файлы в папку test_data/ и запустите:
```bash
python main.py
```
### 3. Результат
В корне проекта появится файл merged_report.xlsx с готовым отчетом.
### 🛠 Технологии
Python 3.10+
Pandas — работа с таблицами
OpenPyXL — чтение/запись Excel

### 💼 Кейс из практики
Задача: Сеть из 5 магазинов присылала отчеты в Excel. Менеджер тратил 4 часа в неделю на их сведение.
Решение: Написал универсальный скрипт, который автоматически находит ключевые колонки, обрабатывает «грязные» данные и создает готовый отчет с аналитикой.
Результат: Экономия 16 часов в месяц, 0 ошибок.
